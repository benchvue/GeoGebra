# GeoGebra Function Visualizations

Interactive math function animations to help students understand how functions transform inputs to outputs.

## Live Demos

1. **[Function 2x + 1 - Original](https://benchvue.github.io/GeoGebra/week03/function-2x+1.html)**  
   Basic function visualization with animated plotting

2. **[Function 2x + 1 - Bottom Layout](https://benchvue.github.io/GeoGebra/week03/function-stacking.html)**  
   Enhanced layout with controls positioned at the bottom

3. **[Function 2x + 1 - x-y drawing](https://benchvue.github.io/GeoGebra/week03/function-x-y-drawing.html)**  
   Advanced version with coordinate stack display showing accumulating points

3. **[Two Functions - x-y drawing](https://benchvue.github.io/GeoGebra/week03/functions-two.html)**  
   Can select two functions (2x + 1 OR 2x -1)
